# 🍷 Wine Recommendation Chatbot

An AI-powered wine recommendation engine built with Streamlit and OpenAI's GPT-3.5-turbo.

## Features
• Sommelier-level recommendations
• Smart pairing logic
• Budget-aware suggestions

## Quick Start

1. Clone: git clone https://github.com/4j57yfnpj9-dotcom/wine-chatbot.git
2. Install: pip install -r requirements.txt
3. Add .env with OPENAI_API_KEY=your_key_here
4. Run: streamlit run app.py

## Usage
Enter food, budget, and preferences. Get wine recommendations!

## Tech Stack
• Streamlit
• OpenAI API (GPT-3.5-turbo)
• Python
